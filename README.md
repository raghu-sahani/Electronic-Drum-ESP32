
# ESP32 Electronic Drum with DFPlayer Mini

This project uses:
- ESP32
- 2 piezo sensors
- DFPlayer Mini
- Speaker
- Green LED
- Red LED

## Working
- Piezo 1 triggers Track 1 and Green LED
- Piezo 2 triggers Track 2 and Red LED

## Pins
- Piezo 1: GPIO34
- Piezo 2: GPIO35
- Green LED: GPIO25
- Red LED: GPIO26
- DFPlayer TX: GPIO16
- DFPlayer RX: GPIO17
